# Red Chili Restaurant Website

A polished, responsive one-page restaurant website built with plain HTML, CSS, and JavaScript.

## Run locally
1. Extract the project folder.
2. Open `index.html` in your browser, or use the **Live Server** extension in VS Code.
3. Internet access is needed for Google Fonts and the hosted Unsplash photos.

## Features
- Responsive desktop, tablet, and mobile layouts
- Sticky navigation and collapsible mobile menu
- Smooth section scrolling and active navigation state
- Swiper-powered hero carousel with autoplay, navigation buttons, keyboard controls, and mouse dragging
- Animated anniversary stamp and interactive menu-item hover states
- Menu category filters
- Reservation form with required-field validation and a minimum date
- Demo reservation confirmation message
- Updated contact-focused footer, search description, back-to-top control, and reduced-motion support

## Before publishing
- Replace the demo address, phone number, opening hours, prices, and email with real details.
- Connect the reservation form to a booking API or backend. The current form is front-end only and does not send bookings.
- Replace the sample social links with the restaurant's real profiles.
- Images are loaded from Unsplash URLs and require an internet connection.
